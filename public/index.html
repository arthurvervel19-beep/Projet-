    Commandes
    • Toucher une unité ou un bâtiment : sélectionner. Toucher deux fois une unité : toutes celles du même type à l'écran.
    • Avec des unités sélectionnées, toucher le sol, une ressource, un chantier ou un ennemi : se déplacer, récolter, construire, attaquer.
    • Glisser un doigt : déplacer la vue. Pincer à deux doigts : zoomer.
    • Appui long puis glisser : sélectionner une zone. Les boutons ronds à droite servent à annuler, à sélectionner par zone et à prendre toute l'armée.
    • Construire : choisissez le bâtiment, touchez ou glissez pour le placer, puis validez avec le bouton vert. Pour un mur, glissez le doigt le long du tracé.
    • But : détruire toutes les unités et bâtiments principaux de l'adversaire.
    • Clic gauche : sélectionner (glisser pour une sélection multiple, double-clic : toutes les unités du même type)
    • Clic droit : déplacer, récolter, attaquer, construire, réparer, définir le point de ralliement
    • Flèches / bords de l'écran / clic molette : déplacer la caméra — molette : zoom
    • Ctrl + 1-9 : créer un groupe — 1-9 : rappeler le groupe
    • H : hôtel de ville — . : villageois inactif — Suppr : détruire — Échap : annuler / pause
    • Les raccourcis des boutons sont affichés dans leur coin.
    • But : détruire toutes les unités et bâtiments principaux de l'adversaire.
